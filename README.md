# معرفی پروژه

## نام پروژه
نام نرم‌افزار در این قسمت درج می‌شود.

## هدف پروژه
هدف اصلی و مشکلی که نرم‌افزار قرار است برطرف کند.

## وضعیت پروژه
در مرحله آماده‌سازی و شناخت نیازمندی‌ها.

## استاندارد توسعه
تمام مراحل تحلیل، طراحی، توسعه، تست و انتشار مطابق فایل `PROJECT_STANDARDS.md` انجام می‌شود.

## دستورالعمل هوش مصنوعی
فایل `AGENTS.md` شامل دستورالعمل‌های لازم برای همکاری Codex در این پروژه است.
